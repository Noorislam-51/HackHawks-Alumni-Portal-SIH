A comprehensive platform that connects alumni, enabling **networking, knowledge sharing, and community building** using a powerful **MERN-like Full Stack** architecture with integrated **AI/ML** capabilities.

## 💡 Project Overview

The Alumni Connect Portal is a robust web application that facilitates meaningful connections between graduates. Our platform provides a centralized hub for alumni to discover fellow graduates, engage in discussions, and expand their professional networks.

## ✨ Key Features (Implemented)

| Feature Category | Core Features Implemented |
| :--- | :--- |
| **User Management** | **User Authentication**: Secure login/registration with **Passport.js** and **JWT**-based verification. |
| **Directory & Search** | **Alumni Directory**: Searchable and filterable list of verified alumni profiles. |
| | **Advanced Search & Filters**: Find alumni by **Batch, Branch, Job Title, or Location**. |
| **Profiles** | **Custom Profile Pages**: Editable personal and professional profiles with education, company, and skills. |
| **Community** | **Community Feed**: Forum and bulletin board for discussions and networking, including Direct Messaging. |
| **UI/UX** | **Responsive Design**: Optimized for all screen sizes using **Tailwind CSS** and **Bootstrap**. |

## 🛠️ Technologies Used

The portal is built on a modern, flexible, and scalable architecture.

### Frontend & UI
| Technology | Purpose |
| :--- | :--- |
| **EJS, HTML5, JavaScript** | Core templating and logic. |
| **Tailwind CSS, CSS3** | Utility-first styling for a sleek, modern, and responsive design. |
| **Bootstrap** | Used for rapid component development and additional responsiveness. |
| **Chart.js** | For data visualization and admin analytics dashboards. |

### Backend & Database
| Technology | Purpose |
| :--- | :--- |
| **Node.js, Express.js** | High-performance server-side environment and web framework. |
| **MongoDB / MongoDB Atlas** | NoSQL database for flexible, scalable data storage (leveraging cloud hosting). |

### AI / Machine Learning
| Technology | Purpose |
| :--- | :--- |
| **Python** | Primary language for Machine Learning model development. |
| **Machine Learning, Python APIs** | Implementing recommendation engines for mentorship and career opportunities. |

### Authentication & Security
| Technology | Purpose |
| :--- | :--- |
| **Passport.js** | Flexible authentication middleware for Node.js. |
| **JWT (JSON Web Tokens)** | Secure, state-less authentication for API access and sessions. |

### Development & Deployment
| Technology | Purpose |
| :--- | :--- |
| **Git, GitHub, Postman** | Version control, collaborative code management, and API testing. |
| **Render** | Cloud platform for reliable deployment and hosting. |

- **Python** (v3.x or higher for running ML scripts)
- **Git**
